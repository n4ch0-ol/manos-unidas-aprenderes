¿Cómo exportar tus chats?
• ChatGPT: Settings → Data Controls → Export data (te llega un mail con ZIP). También podés exportar un chat individual como Markdown desde el menú del chat.
• Gemini: Activity → Delete → Export (descarga un JSON).
• Claude: Aún no tiene export masivo, pero podés copiar el chat manualmente a un .txt.
• Formato universal: cualquier .md o .txt con Usuario: ... y Asistente: ... funciona.
